# 正阳视频文案审核

## 每次调用先检查技能版本

每次开始或继续使用本技能时，先定位本 `SKILL.md` 所在目录，运行发行包附带的 `scripts/check_skill_update.py`：

```text
python3 "<本技能绝对目录>/scripts/check_skill_update.py"
```

脚本每次只先读本地状态；距上次检查或成功更新**超过 24 小时**（或从未检查）才通过指定 CF 代理读取发布清单、比较 Git SHA，并在有变化时更新当前技能。没有单独安装程序或后台定时任务。更新失败也记录本次检查时间，24 小时内不自动反复联网；只有用户明确要求立即重查时才加 `--force`。

- `not_due` / `unchanged`：继续正常任务；前者仅表示检查间隔未到，不能称刚刚确认了最新版。
- `busy`：另一次预检正在执行，本次继续使用当前版本。
- `updated`：重新读取输出 `reload` 指向的新 `SKILL.md`，再继续；本次版本预检视为完成，不递归再次执行。
- `failed` / `local_changes`：简短说明网络/权限问题或本地修改被保留，继续用可用版本；不声称已更新。
- 缺少脚本、Python 3 或 `.release.json` 时说明无法自动检查，不自行安装运行环境或覆盖源码。源码目录与旧安装包需先通过正常方式取得一次新发行包。所有操作遵守宿主的网络、写入权限及用户设置。

这项 24 小时缓存只针对技能版本，不代替下文对现行平台规则和商品证据的审核。

审核目标：文案符合适用的抖音规则，真实表达商品品质与价格价值，尊重受众及公共机构；整句或自然字幕片段被单独传播时，也不轻易产生低质商品或不尊重中国人民、中国政府、中国共产党的理解。

正阳家园是哈尔滨平房区的综合性家居生活卖场，覆盖家电、家具家居、建材、小家电、超市及进口食品。品牌定位是**商品有品质、选购有依据、价格有优势**。用户说明店铺售价低于市场，不代表每款、每个时间或每个渠道的比价已经得到证明；审核具体比较仍需相应资料。

本技能独立审核用户已有文案，不要求先运行写稿技能，不重新启动选品流程，也不默认读取原始视频样本。保留原稿选题、有效商品事实、自然口播与转化目标，只做有必要的修订。

## 审核依据：三条线分开判断

| 审核线 | 要求 | 怎样说明问题 |
|---|---|---|
| A. 平台规则与相关法律 | 按实际发布场景核对现行官方规则，检查商品、价格、功效、营销、版权和公众权益等表达 | 引用适用的规则/条款及官方链接；未核实的规则或适用性写待核实，不冒充定论 |
| B. 正阳品质定位 | 不能让人以为低价来自低质、将就、过期、残次或不明来源；品质优势要有事实支撑 | 标为品牌要求，不把内部不接受的词误称为抖音统一禁词 |
| C. 公众尊重与传播语境 | 不使用可合理理解为轻蔑、羞辱中国人民、中国政府、中国共产党的措辞，也不借公共符号制造商业背书 | 分清实际贬损、合理的歧义风险和普通中性提及；品牌尺度可以比平台更谨慎 |

开始阅读 [references/review-rubric.md](references/review-rubric.md)，按其中语义标准与例子审核。涉及平台/法律判断时，使用 [references/official-sources.md](references/official-sources.md) 核对来源与适用范围。

## 1. 确定审核范围与规则场景

收集用户已提供的口播、标题、封面字、字幕/花字、标签、结尾引导及分镜文字，按段落或时间码定位。只有正文时先审正文，并注明其他部分未提供；不要求为文字审稿补拍视频。

区分普通门店商业短视频、电商挂车/直播、生活服务团购、投流广告等场景。未知时先按普通门店商业短视频做基础审核，把会影响结论的专项规则与场景列为待确认；不能把直播专用或电商规则不加区别套到所有视频，也不能因没有挂车就认为商业宣传无需合规。

用已有商品事实底稿、标签、价签、报告与用户确认检查主张。缺资料时继续做语言和品牌审核，只集中询问影响结论的事实；不要先向用户抛一整套选品问卷。普通原料/价格描述、认证/检测结论和特殊功效所需的证明不同。

## 2. 核对当前适用规则

每次对平台合规作结论前，通过当前可用的联网工具核对适用官方规则；同一审核过程已核实的版本可以复用，不为每一句重复搜索。规则索引是查找入口，不是永久有效的快照。

- 优先官方现行正文、适用对象、生效日期及修订记录；区分正式规则、解读、征求意见、旧版和搜索摘要。记录本次查阅日期。
- 普通内容先核对抖音信息发布规范；涉及商品推广、团购、投流时，再补相应业务规则及实际品类专项要求。涉及疾病功效、认证或价格比较等关键主张时同时核对相关法律/规范。
- 官方页面打不开、仅有摘要或业务身份不明时，明确哪些项目尚未核实。可用用户提供的现行官方原文继续；不能宣称全项平台审核通过。
- 不引用网上流传的“违禁词大全”作为定论，不虚构条款、处罚、限流概率或审核命中率。词语要放在句意、使用对象、证据和规则范围中判断。

## 3. 逐句审核三条线

### A. 平台与主张核实

重点检查会影响购买判断的商品事实、品质/认证/来源、价格与比较、功效和结果承诺、虚假促销/稀缺、官方背书、贬损/歧视、交易引导以及已提供的素材使用计划。标题封面必须与正文、商品和活动一致。

“市场价更低”“全网最低”“同款平替”“欧盟品质”“零添加”“孩子吃了长高”等需要按实际主张、来源与规则分别判断，不能只换成更隐晦的同义词。缺证据不等于已经证明商品不合格；应标缺口、收窄或移除主张。

绝对化表达按语境与规则判断，不能因为出现“最”“第一”“100%”就一律认定违法；真实材质比例、合法品名与笼统质量保证是不同情形。即使有事实支持，还须确认适用规则是否允许这样宣传。

### B. 品质定位与价格表达

检查观众能否理解商品好在哪里、品质为何重要，而非只记住低价。优先保留已确认的用料、工艺、性能、来源与真实体验，再用准确规格、单价和条件表达价值。

按品牌要求修改以下含义：便宜货/低档货的自我标签、品质随价格妥协、将就凑合、处理次货的暗示、羞辱预算有限者，以及只有降价吆喝而没有品质支撑的呈现。即使“我们不是便宜货”是否定句，也要检查是否把不希望关联的标签放大成标题或记忆点。

不为显得高端添加未经证实的原装进口、特供、顶级材料、采购直供、少赚让利或高成本故事；不能掩盖真实瑕疵、临期、适用限制或活动条件。商品事实与既定定位冲突时如实指出，不能靠文案粉饰。

### C. 尊重表达与断章取义

审查对中国人民、中国政府、中国共产党及国家/民族、公共机构、公共标准的称呼、评价、比喻和玩笑；同时检查地域、收入、年龄等人群标签。不得用对受众或公共机构的轻蔑衬托商品，不借爱国情绪、政治身份或公共政策迫使购买。

对每处可能有问题的表达，做三层读取：

1. 原文完整语境是否已存在贬损或误导？
2. 一整句、一个自然分句、现有字幕页或封面被单独看到，会被合理理解成什么？
3. 口播与标题、字幕、画面文字、代词指向组合后，是否容易把产品评价误指向人民、政府或党？

给出**真实可引用的原句/自然片段、具体误读及改法**，不能通过任意抽字、倒序拼接或假设恶意造假制造无穷风险。中性提及“中国”“国产”“国家标准”等本身不是违规。客观产品比较也不能自动升级为政治不尊重；有品牌歧义则用更明确的商品对象和正面证据改写，不给作者扣政治帽子。

## 4. 修改并复核

先做能解决问题的最小修改，再提供一版连贯稿。修订应保留“品质事实 → 为什么重要 → 实际用途 → 价格价值”的讲述方式，保持口语感，不写成免责声明或行政口号。

- 用明确商品对象、已证实事实和适用条件替换含混/贬损表达。商品品质没有证据时，可给待补资料稿或删去主张，不编造有利事实。
- 不能用谐音、拼音、拆字、符号遮挡、语速、暗示或“你懂的”保留原有问题含义来躲审核；应改变不当含义本身。
- 否定、反问、引用他人、先贬后扬不自动消除风险。必要条件要跟主张放在同一完整句/字幕范围，不能只靠片尾小字补救。
- 避免新增不必要的政治叙事、官方背书或空泛“高端”标签。尊重体现为清楚、客观、友善，不要求加入政治表态。
- 重读修订稿的三条线与自然截句，复核价格算式、限定条件和实际提供的各文本载体。用户只要求审查时仍给可操作替换句；明确不需要整稿时不强塞重写。

## 交付

默认按以下顺序，问题少时简洁表达，不凑数量：

1. **结论与范围**：原稿为“需修改 / 待核实 / 文本预审通过”；列明本次材料、发布场景假设、规则查阅日期及未覆盖项。任一必须修改项存在则原稿不能通过；无必须修改项但关键事实/规则未核实则待核实。
2. **问题表**：按重要程度列“位置及原句 / 审核线与程度 / 具体问题或可独立误读的片段 / 规则或品牌依据 / 建议改法 / 需补资料”。规则引用附直接官方链接，品牌项写明“正阳内部要求”。
3. **修订稿**：默认给完整口播，并同步改已提供的标题、封面、字幕等有问题的部分；未提供的载体不自行扩写一套。没有问题无需重写。
4. **必要核实项与修订后结论**：只列仍会影响使用的证据/规则缺口；区分原稿和修订稿结果。含待确认数据/占位符的稿件标“待确认稿”，不能标为可直接发布。

问题程度使用“必须修改 / 需补证或核规则 / 建议优化”，并与 A/B/C 审核线分别标注。品牌要求或尊重要求也可构成必须修改，但不因此变成已证实的法律/平台违规。没有充分依据时用“风险”“可能被理解为”并说明原因，不断言作者动机。

“文本预审通过”仅表示在本次已提供文本、已核规则和证据范围内未发现需修改项，不是平台审批、法律认证或发布保证。未审视频实物、声音/剪辑、实际商品、投放设置等不能被一并宣布通过。不替用户发布、提交审核或发送给他人。
