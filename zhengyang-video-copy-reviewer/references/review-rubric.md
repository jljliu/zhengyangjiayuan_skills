# 审核尺度与改写示例

这里的例句用于帮助理解风险含义，**不是抖音官方禁词表**。判断实际文本时仍需核对语境、证据、发布场景和当前规则。品牌要求可比平台更严格，但两者必须分开标注。

## A. 平台与商品主张：先找证据缺口

| 检查点 | 要核对什么 | 处理方式 |
|---|---|---|
| 商品品质与身份 | 原料、成分、材质、工艺、产地、进口方式、认证、型号、供应商是否与所售准确商品一致；“我试过”“多年经验”是否属实 | 缺资料列待核实，不能把“优质同类通常有”当作本品事实；明确不实则修改 |
| 价格与优惠 | 售价对应哪款/多少量，折算是否正确，活动时间/会员/领券/起购/地区/费用是否说清；比较价来自哪里、是否为场景规则允许的比较方式 | 泛称“市场价”“全城最低”不能由店铺总体定位证明；有外部售价记录也要核对平台是否允许这样比价 |
| 极限词与结果保证 | “最好、第一、100%”究竟是质量/安全保证、限定范围事实、真实比例、品名还是消费提示 | 依规则及证据判断；不机械替换每个“最”，也不以“个人觉得”给绝对质量保证免责 |
| 功效与适用人群 | 普通食品/日用品是否宣称疾病治疗、保证长高/减重等结果，是否把营养参数外推成所有人适用或绝对安全 | 删除无依据或不允许的功效；不能将保证改成暗示继续保留同一问题 |
| 营销与社会权益 | 虚构限量/原价/破产/亏本/抢购，恶意贬损同行，羞辱人群，站外交易引导、虚假身份或公共机构背书 | 按当前业务规则确定问题；普通到店地址不自动等于违规站外交易，正常评论问题不自动等于违规诱导互动 |
| 文案之外的已提供计划 | 标题与正文是否兑现一致，是否安排未经授权的他人片段/音乐、可识别个人资料、误导性 AI 影像或官方标志 | 只审提供的计划/素材，必要时列授权、标识或规则待核；不声称文字修改就解决实际视频问题 |

依据核对方向见 [official-sources.md](official-sources.md)：信息发布规范、商品推广规则、价格专项、广告真实准确及功效要求、绝对化用语语境判断、引证数据与限定条件。上表是检查任务，具体违规结论应附实际适用的官方依据。

## B. 品牌定位：品质有依据，价格有价值

希望形成的认知是：**买得到有品质的商品，也能把价格和家庭开销算明白。** 不把“高价”作为高品质证明，不把“低价”写成低等级，不按收入划分谁配享用好商品。

### 必须改的含义与较稳妥的方向

| 原表达示意 | 为什么不符合正阳要求 | 改写方向（仍需事实支持） |
|---|---|---|
| “我们就是卖便宜货的”“低档价，凑合用” | 给店铺贴低等级标签，暗示价格与品质一起降低 | 删去等级标签，直说本品已确认的材质/表现与准确价格 |
| “这个价还要什么品质”“便宜，能用就行” | 明示顾客应接受品质妥协 | 说清实际好用在哪里及适用范围，不能只换成“性价比高” |
| “我们不是卖垃圾货的”“便宜没好货？我们偏不” | 否定或反问仍把负面标签与店铺绑定；被做成封面时更突出 | 直接从正面品质证据开场，不重复负面标签来辩解 |
| 用“地摊价、白菜价、亏本甩货”作为整条文案的主要记忆点 | 容易形成廉价、低等级或急于处理商品的印象；属于品牌表达问题，不能一概称平台禁词 | 改用商品品质与明确价格说明价值；真实活动条件保留，不编造亏本或货源原因 |
| “穷人专供”“有钱人才配买”“专割不懂的人” | 贬损顾客、制造阶层优越或欺骗联想 | 面向具体家庭需求与预算，友善讲清怎么选 |
| “全是大牌尾货，所以才便宜” | “尾货”及低价因果若未核实会制造来源/品质疑虑 | 核实事实；不能擅自换成“工厂直供”，无依据就只给实际品质与价格 |
| “最顶级的品质，全城最低价” | 用无法支撑的两个极端结论冒充品质定位 | 用已确认的一两个品质及准确规格/单价取代；另核规则适用性 |

“实惠、划算、性价比、优惠”不是天然低质标签。要看是否与品质依据、具体商品和条件一起讲清。对全篇只有低价吆喝、没有任何商品品质理由的稿件，指出定位缺口并请求必要事实，不能靠多加“高端、品质”两个词解决。

### 不能伪造的低价原因

采购直供、渠道精简、减少中间环节、规模采购、少赚利润、补贴、成本优势等都是商业事实。即使用户确认售价低于市场，也不能自行选择其中一种解释。没有原因资料，直接说明商品品质和已确认价格即可。

真实临期、瑕疵、展示品、特殊版本、售后限制或活动门槛不能为了维护高端形象删掉。若本条促销的商品事实不符合既定定位，提出调整表达或选品的建议，不隐瞒实际状态。

## C. 尊重与独立传播：审含义，不审政治忠诚

按用户要求，中国人民、中国政府、中国共产党均不得成为卖货时贬损、讥讽、刻板归纳或羞辱的对象。对中国、民族、地区、公共标准和公共机构的措辞，也要检查是否会合理地传递这种含义。中性商品介绍不需要添加政治表态。

| 风险模式 | 应识别的含义 | 改法 |
|---|---|---|
| 用外国商品贬低国产或中国消费者 | 如“国产都不行，进口才放心”把产地直接写成等级/安全结论；对消费者作“好骗、没见识”的群体归纳 | 聚焦具体商品与可核实差异，产地如实交代；不靠贬低国产或受众建立品质 |
| 用公共标准当负面陪衬 | “国家标准也就那样”容易被单句理解为轻蔑标准/监管；不等于一切标准比较都违规 | 尊重地说明适用要求、本品具体指标与该指标意义。不能把基础合规或其他国家标准自动说成更优 |
| 借政党、机关、政策或领导形象背书 | “政府推荐”“内部特供”或政治符号与商品强绑定可能既缺事实也涉及广告限制 | 去掉不适当背书；必要的客观政策/认证信息须查适用范围，不能改成隐晦影射 |
| 玩政治称呼、历史口号、公共事件的梗 | 商品促销的双关、戏谑、影射容易转向对公共对象的不尊重或不当商业利用 | 换成商品、使用场景和价格的普通描述，不把政治内容作为卖点 |
| 模糊代词或前后反差 | “他们不懂”“这样的标准不值得信”对象不清，配合邻近机构/人群名可能被误指 | 写出准确商品/方法对象，删除贬损；不能只靠后一句解释“我不是那个意思” |

“国产”“中国标准”“进口”“政府”“党”等字词的出现本身不构成问题。不得把正常来源说明、客观标准引用或对具体产品的实证比较标成侮辱。尊重风险结论要指出具体含义与语言机制，不推断作者立场。

### 可操作的截句检查

检查完整句、自然分句、现有字幕页和封面；保留真实顺序与可见的文字组合。判断脱离前后句后，是否仍准确、对象明确、尊重受众。不要抽掉半个词、倒序重排或无限设想恶意剪辑。

有风险时可在问题表中写：

> 原句/自然片段 → 被单独理解的含义 → 属于品牌歧义还是规则问题 → 能独立成立的替换句。

例如“我们不是便宜货”按品牌要求改为直接描述已确认的品质；“国家标准也就那样”改为具体、尊重的指标说明。不能把“补一句尊重所有人”当成保留原有贬损的修复。

## D. 修改后的质量检查

1. 原稿里可保留的商品事实、主题、节奏与目标是否保留？没有为安全把有用信息全部改成空泛口号？
2. 品质与价格是否都有清楚对象与证据，没有新添“高端进口、同款、直供、低于市场”等未经确认的事实？
3. 修订是否改变了问题含义，而非谐音遮挡、引用、否定或免责声明？
4. 同一风险是否在标题、封面、字幕或结尾仍有残留？只提供文本时，是否准确说明未审声音和实际画面？
5. 规则问题与品牌要求是否分别标明？没有以“绝对安全、保证过审”结束审核？
