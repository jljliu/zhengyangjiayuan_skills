# 正阳视频文案创作

为正阳家园卖场创作抖音视频，把“搜视频 → 提文字 → 拆结构 → 写方案”走完，四步缺一不可。参考文案必须来自抖音公开页面，缺失处明确标注，禁止编造视频里的话。

## 账号背景（每次创作都基于此）

正阳家园是位于哈尔滨的大型综合性家居生活卖场，地址为黑龙江省哈尔滨市平房区南海路 2 号。卖场覆盖家居全品类，包括家电、家居家具、建材与小家电；同时内设超市，供应日用商品，并汇集大量进口食品，方便家庭一站式购齐。

创作时把握以下要点：

- 立足本地（哈尔滨平房区及周边家庭客群），强调“品类齐全、可到店体验、一站式采购”的便利；
- 选题可围绕：家电/家居/建材的选购与避坑、小家电好物、超市好物与进口食品尝鲜，以及换季、装修、节日、囤货等场景和到店活动；
- 突出真实卖场、品类全、进口食品稀缺、售后与体验等卖点；
- 结尾引导与目标一致（到店地址、关注、评论、私信或活动）。

## 开工前确认输入

确认以下信息；用户没说清又不影响检索的，先用已有关键词开工、边做边补：

- 本次主推品类/单品或活动、要表达的核心卖点
- 目标人群、视频类型（口播 / 剧情 / 种草 / 知识科普 / 带货 / 探店 vlog）
- 期望时长、转化目标（到店 / 涨粉 / 评论 / 收藏 / 私信 / 下单）

## 执行通道与边界（默认不用浏览器）

- **找视频用 `general_search`**：查询串用 `site:douyin.com` 或 `site:iesdouyin.com` 限定抖音站点，后接关键词；可结合品类与本地，如“哈尔滨 家电怎么选”“进口零食 推荐”“装修 建材 避坑”。
- **提文字用 `web.fetch`**：打开搜索得到的 `https://www.iesdouyin.com/share/video/<id>` 分享页，可获取完整标题、口播/文案正文与话题标签。
- 只做读取与分析，不点赞、不评论、不关注、不发布。

## 第 1 步：搜索相关抖音视频

1. 围绕选题构造 3–5 组查询词，分别搜索以覆盖不同说法：
   - 核心品类词：如“家电推荐”“进口零食”；
   - 场景/痛点/人群词：如“装修 建材 避坑”“小家电 租房”“进口食品 小孩”；
   - 可加年份或“哈尔滨”等本地词，保证时效与相关性。
2. 按以下标准挑选 5–10 条参考视频：
   - 与本次品类、目标人群高度相关；
   - 视频类型与要做的形式匹配（口播 / 种草 / 测评 / 探店 / 剧情等）；
   - 内容完整、表达清晰，时效较新。
3. 逐条记录：

| # | 标题 | 作者 | 发布时间 | 链接 |
|---|------|------|----------|------|

## 第 2 步：提取视频文字内容

对入选视频逐个 `web.fetch` 其分享页，读取并整理：

- 完整标题（重点看开头第一句）；
- 口播/文案正文全文（分享页通常含较完整逐字稿；个别页面只有标题，则结合搜索摘要，并标注“正文不完整”）；
- 话题标签 `#…#`，汇总高频/高相关标签。

每条整理成：【标题】【正文/口播】【话题标签】。

- 不得凭标题想象、补全视频里没说的话。

## 第 3 步：拆解结构、总结规律

读取 [references/viral-structure.md](references/viral-structure.md)，按框架逐条拆解，再横向对比：

- **开头 3 秒钩子**：属于哪一类（痛点 / 反常识 / 利益承诺 / 悬念 / 身份点名 / 冲突对比 / 数字清单 / 提问…），原话怎么写；
- **正文结构**：痛点-方案、总分总、前后对比、步骤清单、故事案例、误区反转等；
- **节奏与完播**：时长、每隔几段/几秒一个信息点或转折、如何留人到结尾；
- **情绪与共鸣点**、梗/BGM、画面信息；
- **结尾动作**：到店 / 关注 / 点赞 / 评论提问 / 收藏 / 转发 / 下单引导；
- **标题与话题标签**写法。

输出两部分：① 单条拆解表；② 跨视频**共性规律**（反复出现的钩子类型、结构、标签、引导语）——这是第 4 步创作的直接依据。

## 第 4 步：创作方案（1 个最佳 + 4 个备选）

依据第 3 步的共性规律，每次固定产出 **5 个方案：1 个最佳方案在前，4 个备选方案在后**，彼此用不同钩子、结构或风格拉开差异，并贴合正阳家园背景与本次主推品类。每个方案都必须包含以下完整内容，不能只给标题或开头：

1. **视频标题**：关键词前置、带钩子，可与开头第一句呼应。
2. **标题封面设计**，分两部分写清：
   - **封面内容**：画面主体、构图、背景、人物或产品位置、色调风格（可使用卖场实景、商品特写或前后对比）；
   - **封面文字**：主大字（建议 6–12 字，放大最核心的冲突或利益点）、副标题或角标文字。
3. **逐秒分镜脚本**：按时间分段（每 2–4 秒一段，覆盖整条视频），每段写清三要素：
   - **说什么**：该时段的口播/台词原文；
   - **拍什么**：景别、画面内容、人物动作、运镜；
   - **屏幕文字**：字幕、花字、贴纸或需要强调的词。
4. **话题标签** 3–8 个；**BGM/音效**建议；**结尾引导**：与转化目标一致的明确动作（可自然带出“正阳家园·哈尔滨平房区南海路 2 号”，但不生硬堆砌）。
5. 预计时长；注明本方案借鉴了哪些视频的什么手法，只借鉴结构与方法，**不照抄、不洗稿他人原创表达**。

最佳方案最完整、最贴合目标，放在最前并标注“最佳方案”；随后依次列出“备选方案 1/2/3/4”。每个方案的分镜统一用表格：

| 时间 | 说什么（口播/台词） | 拍什么（画面/景别/运镜） | 屏幕文字（字幕/花字） |
|------|--------------------|--------------------------|------------------------|
| 0–3s |  |  |  |
| 3–6s |  |  |  |

## 交付清单

1. 视频采集表（含标题、作者、发布时间、链接）
2. 单条结构拆解 + 共性规律总结
3. **5 个完整方案：最佳方案（在前）+ 备选方案 1/2/3/4（在后）**，每个方案含：
   - 视频标题
   - 标题封面设计（封面内容 + 封面文字）
   - 逐秒分镜表（每几秒：说什么 / 拍什么 / 屏幕文字）
   - 话题标签、BGM、结尾引导、预计时长
4. 正文或资料缺失处如实标注
