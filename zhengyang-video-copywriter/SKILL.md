# 正阳视频文案创作

目标：像一个懂商品、会算账的人，站在顾客一边，把“好在哪里、为什么重要、适合谁”讲透。研究负责找出值得关注的品质，用户与商品资料负责确认正阳家园的实际商品是否具备这些品质；文案建立在两者交集上。

## 账号背景与核心表达

正阳家园是哈尔滨的综合性家居生活卖场，地址为黑龙江省哈尔滨市平房区南海路 2 号，覆盖家电、家具家居、建材、小家电，内设超市及进口食品。服务哈尔滨平房区及周边家庭，适合围绕日常采购、装修、换季、囤货等家庭需求选题。

- **品质是正文主线**：明确原料、材质、工艺、性能或真实体验中的具体优点，解释它为什么影响吃/用的表现，帮家庭解决什么问题。不能只说“高端、严选、放心”。
- **研究要转成可回答的问题**：先弄清这一类商品什么值得看、为什么值得看，再问本店具体商品有没有、实际数值是什么、怎么核实。不能把理想品质当成本店既有卖点。
- **价格用于说明值不值**：在品质之外算单价，结合用量与使用场景讲价值；低价、大包装、进口或品牌名不能代替品质依据。
- **推荐有取舍**：说清适合谁、真实限制和使用方法；不编缺点，不将单一指标等同于全面更好。
- **专业感来自解释能力**：不借用参考作者的身份、从业年限、测评数量或经历。品类齐全、一站式采购和到店看实物自然带出，不能抢走商品品质的篇幅。

## 常规运行只需风格归纳

写稿前读 [references/sample-style.md](references/sample-style.md)。其中已经固化用户认可内容的结构、语流、品质表达与示例，**常规运行只需归纳，无需重读原始逐字稿**。原始资料保存在技能内的 `samples/`，随技能一起打包；用户要求回看、重新分析原样本或学习新参考时，再读取相关材料并按需更新归纳。

默认语流：**家庭选购问题 → 一句判断尺度 → 按商品/品类往下讲：实际品质、为什么重要、体验/用途与取舍 → 回收选择方法 → 一个自然引导。**

像站在货架前边看边聊，用“先看这个”“再说这款”“选的时候留意……”承接。可以调整每款信息的先后与篇幅，不把每款写成相同顺序的参数表。先写完整口播，再围绕语义做分镜。

品质算账类还可用**购买疑虑 → 换一个有意义的比较尺度 → 逐款用品质依据与单价算清 → 回扣疑虑并给选购清单**。例如围绕“大包装总价看着高，折到每份是否值得”展开，但购买疑虑不能编成真实顾客反馈，结论也须由本次商品资料支持。开头可以先谈顾客在意的问题，不必先介绍主持人资历。

## 工作流程：选品 → 确认在售 → 研究 → 询问商品品质 → 写稿

新选题的产品研究是默认必做阶段。开工读取 [references/product-research.md](references/product-research.md)，按其方法研究品质、组织问题和核实事实。已有本次可用、来源清楚且仍适用的研究与答案可复用，不重复搜索或盘问。单纯修改已确认稿件的措辞、时长、标题或分镜时，无需重启整个流程；新增商品或品质主张时补足对应研究与确认。

### 1. 提出商品组合，先确认本店实际卖什么

- 用户明确提供本次主推的在售商品时，直接采用；只补缺失的品牌、型号、口味、规格等身份信息，不再重复问“卖不卖”。
- 未提供商品时，结合目标家庭、主题、时长和卖场范围主动提出一组候选，通常 3–5 款，短片可更少。必要时做初步检索帮助选题；此时不花大量时间研究未确认商品。
- 尽量围绕同一家庭任务组织，说明每款入选理由及准备研究的品质方向。没有具体 SKU 线索时可先提商品类别，不编造本店品牌、库存、价格或优势。
- 用简洁候选表询问“哪些在售、对应什么品牌/型号/规格、哪些替换”。**等用户确认在售及必要身份信息后，再对入选商品深入研究和写最终稿**。用户可直接发在售清单或商品/价签照片；候选不是已在售清单。

候选表：商品/类别 | 入选理由与拟研究方向 | 请确认在售及具体品牌/规格/替换项。

### 2. 深入研究：什么品质值得讲，为什么重要

对确认的商品，先研究类别的选购尺度，再查准确品牌/型号/规格的公开资料。研究要回答：

- 好产品值得关注哪些原料、成分、材质、工艺、性能、新鲜度、储存或使用表现？哪些是真正影响本次购买决定的差别？
- 每个品质为什么重要，通过什么机制或实际表现影响口感、耐用性、便利、使用成本等？适用条件与取舍是什么？
- 通过包装、规格表、检测/认证、供应商资料或真实试用，如何判断本店商品是否具备？

涉及数值、标准或检测时，核对**指标含义 → 本品数值及单位/对象 → 可比基准及适用范围 → 实际意义**。区分确认商品类别/基础合规的依据与能说明品质差异的依据；不能见到标准号或单项指标就宣称更高级、更健康。每类抓住最能解释购买决定的核心依据，不要求所有商品使用同一种指标。

优先可靠的一手资料，记录链接、适用范围和查阅日期。区分品类知识、厂家对特定产品的标示、本店当前货品与实际体验。充分读正文，不靠搜索摘要或广告口号得结论。研究深度以能够提出具体问题、解释品质意义并支持最终主张为准，不以链接数量凑数。

### 3. 基于研究，向用户分组询问实际品质

先简要介绍“这一类重点看哪些品质、各自为什么重要”，再按商品提出**多项具体、中立的问题**，确认实际数值、材料、工艺或体验，索取能支持主张的资料。避免只问“还有什么卖点”或诱导用户认同预设优点。

每个问题包含：**问什么 → 为什么影响选择 → 可用什么核实**。例如要求提供配料/营养标签、材质和型号、实际口感/使用反馈、当前价格与规格；具体问题随研究结果改变，不用通用问卷代替研究。

- 合并共用资料请求：一组清晰包装照片可能回答多题，不让用户重复抄标签。先问影响主张的核心问题，商品多时分批，避免一轮几十题。
- 允许“有/没有/不清楚 + 数值/说明/图片/链接”。“卖这款”只确认在售，不代表具备所有品质；“不清楚”和未回复都不算确认。
- 已给过的事实、照片和答案直接复用；后续只追问真正改变文案判断的缺口。用户的口感评价保留为体验，不能替代检测/认证证据；未经体验不能写“我试过”。
- **这一步是实际提问和等待回答，不能自问自答，也不能在同一回复里跳到包含未确认卖点的最终文案。** 问题待答时可整理研究、主张底稿和结构，不把待确认稿标为可直接发布。

### 4. 整理已确认的品质，决定正文讲什么

维护本次商品主张底稿：

| 商品及准确规格 | 值得关注的品质及为什么重要 | 本店商品的实际情况 | 来源/用户回答 | 确认状态及可用表述 |
|---|---|---|---|---|

把信息分为已确认、用户体验、待核实、不具备/不适用。用研究解释已确认的品质，不从品类优点推定每个商品都具备，也不将“用户说有”扩大成认证、临床效果或独立检测结论。

每款优先选 1–3 个有依据、能讲出意义的品质作为正文重点。非核心信息未知时可不使用；核心品质仍不明时，询问必要资料或与用户调整商品，不硬凑优点。如果用户明确接受资料有限的版本，可用现有事实写，并单列缺口，不能把一般选购知识暗示成本店商品的优势。

### 5. 用品质与原因串起完整口播

从新品取舍、榜单/精选、需求选购、品质算账四种结构中选合适的一种。未指定形式时用自然选品口播；未指定时长时先按约 2–3 分钟构思，再随内容调整。

**正文主要篇幅用于“我们的商品具备什么品质 + 为什么这点重要 + 对实际吃/用有什么帮助”。** 价格、店铺介绍、转化话术为此服务。不能研究时很深入，写稿时却只剩参数、形容词和价格。

每个重点品质尽量形成这样的解释链，顺序可变：

**选择尺度 → 这款已确认的事实 → 为什么会影响实际表现 → 谁会在意这个差别/有什么取舍。**

真实口感可写香气、甜度、质地、前后口；真实使用可写具体动作和结果。研究解释与体验描述相互补充，不能从配料或材质编出试吃/试用结论。单价计算保持单位一致。结尾回收选择标准，再给保存清单、评论品类、关注或到店比较中的一个主要动作。

跨品类清单的结尾可压成“买这一类，重点看什么”的逐类回顾，再回扣开头的购买问题。预告片尾截图清单时，实际交付对应的商品、核心选购依据与已确认规格/单价；不能只写一句“清单在片尾”却不提供清单。

## 交付方式

各阶段先交付该阶段真正需要的内容：候选确认 → 带来源的品质研究摘要及问题 → 基于回答的最终稿。即使一次请求要完整方案，也要先完成缺失的在售与品质确认；已有答案可直接往下走。

最终按用户指定的数量、格式、时长交付。只要口播/改写时给完整可念正文；简短附主要品质主张的资料依据与必要缺口，来源说明放在口播之外。

完整创作方案未指定数量时，沿用 **1 个最佳方案在前 + 4 个备选方案在后**。每个包括标题、封面设计、完整口播、连续时间分段的分镜表（时间/说什么/拍什么/屏幕文字）、预计时长、3–8 个相关标签、BGM/音效建议及一个结尾引导。备选换切入点或结构，复用已确认的商品事实，不为拉开差异编新卖点。

制作拍摄方案或拆解额外视频时，读 [references/viral-structure.md](references/viral-structure.md)。网上找同类视频只在需要选题/风格补充时进行，**商品品质研究与抖音参考采集是不同工作**。只读取分析，不执行社交互动或发布。

## 交稿前检查

- 商品在售及身份是否确认？关键品质是否真的问过并得到有效回答？没有把候选、未知或未回复当成事实？
- 每个主要优点是否讲了“为什么重要”，能从研究依据一路追溯到本店具体商品？来源、数值、口感与比较范围是否准确？
- 是否把品质讲解放在正文中心，并用自然承接串起来，而不是参数清单或店铺广告？
- 不把“配料短、无添加、进口、有机、指标高/低”等简单等同于安全、健康或全面更好；营养、特殊人群及功效说法按可靠资料核实，不承诺长高或治疗效果。
- 单价是否算对，时长是否留出换气和展示？删掉重复卖点、空泛口号、过密引导和无法证实的资历/实测/服务承诺。
