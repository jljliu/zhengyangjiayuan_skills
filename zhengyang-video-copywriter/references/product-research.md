# 商品品质研究与确认方法

用于选品确认后的深入研究、向用户提问和确定最终主张。目标是找出真正值得讲的品质，并说明这些品质为什么重要；不是为每件商品搜一组好评或替预设广告词找佐证。

## 1. 分清四类信息

| 信息 | 解决的问题 | 不能推出什么 |
|---|---|---|
| 品类选购知识 | 这类商品哪些品质值得关注、为什么、如何比较？ | 本店某款一定具备这些品质 |
| 准确产品的公开资料 | 这个品牌、型号、配方、规格宣称或标示什么？ | 当前门店货品批次、价格、储存和体验都相同 |
| 本店商品资料与用户确认 | 卖的具体是哪款？包装、进货/储存、价格、服务是什么情况？ | 用户肯定回答就等于独立检测、官方认证或功效证明 |
| 实际体验 | 谁在什么条件下吃/用过，观察到什么？ | 一次主观体验适用于所有人，或能证明某工艺/成分一定存在 |

两条依据都要成立：**这个品质为何有价值**有研究支持，**本店商品确有这个品质**有相应产品证据。不能把“优质同类通常有 X”改写成“我们这款有 X”。

## 2. 怎样研究得够深入

### 从类别问题到具体商品

围绕本次家庭任务，先识别会改变选择的品质，再查所售型号与规格。搜索可组合品类名、原料/工艺/性能、选购指标、标准适用范围，以及品牌/型号/官方规格。不要只搜“某某产品优点”。

按相关性检查这些方向，不要求每类全部覆盖：

- 食品/生鲜：原料、配料与含量、产品类型、工艺、日期与储存、营养标示、可验证来源、口感与制作方法。
- 日用品/纺织/清洁：材质与成分、结构/工艺、尺寸/重量/数量、适用范围、标签支持的用途、真实使用表现。
- 家电/小家电：准确型号、容量与结构、与家庭任务相关的性能、测试条件、清洁维护、能耗和服务条款。
- 家具/建材：准确材料、结构、尺寸、适用环境、工艺、对应型号的检测内容、维护安装与服务。

每个候选品质要能回答：

1. **是什么**：明确指标/属性，避免“高品质、天然、高级”这种无法核实的词。
2. **为什么重要**：解释它与实际表现之间的关系；区分有支持的机制、厂家宣传和个人偏好。
3. **怎样看**：标签哪一项、什么资料或什么实际观察能确认？
4. **何时不适用**：是否与家庭人数、使用方法、配方、规格或测试条件有关？有没有取舍？
5. **能说到哪一步**：资料只证明某个指标，就不要扩大成全方位更好。

对主推品质多做核对，略去与本次选择无关的参数。研究完成的标准是：能提出具体可回答的问题，能解释意义，能指出支持主张的证据及其边界。

### 来源与核实

- 优先品牌/生产商的准确产品页面、说明书/包装、标准发布机构、监管部门、认证/检测机构公开资料；营养或健康相关解释用可靠专业机构或研究来源核对。
- 厂家资料适合核对自己的配方、材料、型号和参数；论证其“比别人更好”需要相应可比依据。电商描述、媒体测评可提供线索，不能独自证明重要品质主张。
- 阅读原文并记录支持段落的意思，不仅引用搜索摘要。核对地区、型号、口味、规格、配方版本、发布日期与查阅日期；价格和标准是否适用要另核对。
- 引用标准时，区分适用范围、基础要求和可证明的差别。不仅因为有标准号就称“高于国标”，不把基础合规包装成独有优势。认证也要核对主体、覆盖产品和有效性。
- 不同来源冲突时如实记录，寻找更直接材料或向用户询问，不挑最利于销售的说法。
- 无法访问、无法联网或无法核实时明确说明。可用用户提供的可靠原文继续；缺少依据的部分列为待研究，不能用常识猜测冒充已完成研究。

### 数值与基准：解释差别，而不是堆权威词

对准备写进正文的指标，研究并向用户核对：指标定义、实际数值与单位、检测/标示对象及日期，以及参照基准的来源、版本和适用范围。必要时确认它针对原料还是成品、某个批次还是整个产品，先确定可比再解释高低。不能把某个标准中的限值用于不同对象，也不能从单一指标直接推定新鲜、全面安全或健康功效。

区分三种用途：**确认产品类别的标示、满足基础要求的证据、说明有意义差异的指标**。前两种可以教顾客辨认商品，却不自动证明高于同类。检测项目数量也不等于全部合格或没有风险，须看报告内容与范围。每类选最相关的一两个核心依据展开，不为显专业把整张检测表念出来。

价格比较同样明确基准：同款或可比商品的规格、单位、渠道、时间和活动条件。优先折到相同重量、体积、数量或适当使用单位；不同材质/尺寸/性能有差别时说明差别，不能只凭低单价得出同等品质更划算。

研究摘要使用以下结构，按实际内容填写：

| 商品/类别 | 值得关注的品质 | 为什么重要及适用条件 | 怎样核实 | 来源链接与适用范围/查阅日期 |
|---|---|---|---|---|

最终展示简明结论和直接支持它的链接即可，详细资料用于提问和写稿，不把研究报告全部念入口播。

## 3. 怎样把研究变成多项问题

先给用户一段简短研究结论，再按商品分组提问。每题清楚说明实际要确认的内容、为什么影响选购、可用什么资料回答。以下只是**提问形态示例**，不代表已做过对应商品的研究；实际问题必须根据本次研究与已知资料调整：

| 商品/研究方向 | 具体问题形态 | 意义与回答材料 |
|---|---|---|
| 食品的原料与产品类型 | 包装上的完整产品名称、配料顺序、相关原料含量分别是什么？能发对应标签吗？ | 确认研究中的品质是否对应实际配方，不能只看包装正面名称 |
| 食品的工艺与储存 | 这款明确标示什么工艺、储存条件和开封后要求？门店目前怎样保存？ | 分开核对产品要求和门店实际情况，不用工艺名称代替储存事实 |
| 研究选出的关键指标/检测 | 实际数值与单位是什么，针对原料还是成品、哪个批次？有没有标签或报告显示日期、检测范围及结果？ | 对照已核实的适用基准解释差别，不能只问“是不是比标准好”或仅凭检测项目数作结论 |
| 食品的口感表现 | 实际试吃时香气、甜度、质地怎样？前几口和吃多后有什么区别？谁试过、怎样准备的？ | 用真实体验描述可感知差别，不从标签编体验，不诱导用户回答“好吃” |
| 洗脸巾的材质与规格 | 材质比例、每片尺寸、每包片数、重量/克重（如标有）是什么？ | 确认具体材料与可比较规格，不由某种纤维直接推定柔软、厚实或不掉絮 |
| 洗脸巾的实际表现 | 干用/湿用分别有没有试过？擦拭、拉扯时是否破损或掉絮，实际感觉怎样？ | 将可描述的使用表现与材料标签分开，可附试用记录或演示 |
| 家电的性能与适用性 | 准确型号是什么？研究中的关键功能/指标在说明书哪里标明，适用条件是什么？本店演示过吗？ | 不把同品牌其他型号的功能移植过来，也不把实验室条件当所有家庭效果 |
| 全部商品的价格与服务 | 目前规格、售价、活动条件/期限分别是什么？要讲的安装、保修或其他服务具体如何约定？ | 用价签/活动规则/服务条款算值不值，不将别店价格或未确认服务写入 |

采用价格疑虑/品质算账选题时，再问用户是否有可用的比较价及其渠道、日期、规格和活动条件；没有则只核算本品并解释品质价值，不编造店外售价。

问题按商品组成容易回复的几组：先收集能同时回答多题的标签、规格表或照片，再问无法从中得出的核心细节和真实体验。长清单分批推进，不一次抛几十题；但也不能为了少问问题而省掉决定品质主张的核实。

用户可以逐项答“有/没有/不清楚”，并补数值、描述、图片或链接。不要因为用户说“有”就补出未提供的数字、认证名、供应商或体验。不要再次询问已经回答的项目。

本轮只输出研究摘要及待答问题，等待回答后进入事实整理；如果同时存在多个待确认商品，不将未答商品抢先写成最终推荐。

## 4. 收到回答后怎样处理

- **有资料支持**：记录具体数值和来源，结合类别研究解释意义；表述强度与材料匹配。
- **用户给出具体事实但无独立资料**：保留“用户提供”的来源身份。普通商品描述可据此起草；需要准确数字、认证/检测或特殊功效的主张应核对对应资料，不能伪装为已独立验证。
- **实际体验**：写明可观察的感受及必要条件，不冒充主持人亲测；需要第一人称时先确认主持人确实体验过。
- **没有该品质**：不要强行解释成另一种优点。寻找商品真正具备、仍有价值的品质，或与用户改选商品。
- **不清楚/未回复**：保持待核实。非核心项可从文案删除；核心主张缺证据时先补材料或调整选品。不可将“资料缺失”本身当产品缺点。
- **与公开资料矛盾**：核对是否型号/配方/地区/批次不同，向用户只追问这项差异，未解决前不用有争议的主张。

候选变更或新增商品后，补做对应在售确认与研究，不需要让其他已确认商品从头再来。用户接受资料有限稿时只用现有依据，不能靠泛泛“严选好货”填补品质空白。

## 5. 从研究到底稿到正文

最终每款抓住 1–3 个真正重要的品质，把三件事连起来：

**这一类为什么看这个 → 本店这款具体有什么 → 这些品质对顾客有什么实际意义。**

能证明“原料是什么”的资料用于原料主张；能证明“用起来怎样”的记录用于体验主张。不能只把研究得到的参数塞进字幕，把“为什么重要”留在报告里。机制复杂时用一句通俗解释，避免技术名词串联；解释不确定时宁可收窄，不编一条听起来合理的因果关系。

最终文案外附简短主张依据：商品、重点品质、研究来源、本店确认材料及未使用的关键未知项。同一组研究可供多个脚本角度复用；价格、版本、时效或选品变化时更新相关部分。
