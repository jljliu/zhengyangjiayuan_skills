# 抖音爆款结构拆解框架

本文件在“第 3 步拆解结构”和“第 4 步创作文案”时读取。用它给每条视频归类、找共性，并直接指导创作。例句为通用模板，使用时替换成具体主题；不要照抄任何具体视频的原创句子。

## 1. 黄金 3 秒钩子类型库

完播和互动大多由前 3 秒决定。判断每条视频用了哪类钩子、原话怎么写；创作时优先复用同类内容中反复出现的类型。

| 钩子类型 | 作用原理 | 写法/句式模板 | 适用内容 |
|---|---|---|---|
| 痛点直击 | 让目标人群“说的就是我” | “是不是每次你一___就___？”“___的人，一定懂这种___” | 知识、种草、带货 |
| 反常识/颠覆认知 | 制造认知冲突，想看你怎么解释 | “你一直以为___，其实正好相反”“别再___了，越___越___” | 科普、干货、避坑 |
| 利益/结果承诺 | 直接给可预期的好处 | “___天教你___”“学会这招，___不再___” | 教程、带货、知识 |
| 悬念/好奇缺口 | 给结果不给过程，勾着看完 | “最后一个 90% 的人不知道”“看到第___秒我惊了” | 剧情、盘点、故事 |
| 身份/人群点名 | 精准筛选观众，提升相关度 | “___的女生/宝妈/打工人注意了”“在上海___的，先别划走” | 垂直、本地、人群号 |
| 冲突/对比 | 强反差产生张力 | “同样是___，为什么别人___你却___”“___前 vs ___后” | 种草、改造、剧情 |
| 数字/清单 | 具体数字显得确定、可预期 | “___的 3 个方法，第 2 个最管用”“只要 5 步” | 干货、盘点、教程 |
| 提问 | 激活思考与评论 | “你有没有想过，为什么___？”“如果是你，你会怎么选？” | 话题、互动、剧情 |
| 热点/梗/BGM | 借熟悉感降低划走率 | 套用当下热门梗、热门 BGM 的固定开场 | 泛娱乐、追热点 |

要点：一条视频常组合使用（如“身份点名 + 痛点 + 悬念”）。记录时标注主钩子和辅助钩子。

## 2. 常见正文结构模型

判断每条视频的骨架，创作时套用同类验证过的模型。

- **痛点 → 放大后果 → 给方案 → 行动**：先戳痛，再讲不解决的代价，最后给方法/产品和动作。适合带货、知识、服务。
- **结论先行（总分总）**：开头抛观点/结果，中间分 2–4 点论证，结尾总结+引导。适合口播、观点、科普。
- **前后对比**：展示“之前多差 / 之后多好”，中间讲做了什么。适合改造、种草、效果展示。
- **步骤清单（How-to）**：按第 1/2/3 步拆解，每步一个信息点。适合教程、干货，天然高收藏。
- **故事/案例**：人物 + 处境 + 冲突 + 转折 + 道理。用具体细节代替说教，完播和共鸣强。
- **误区盘点/反转**：列举常见错误做法并逐个纠正，或先立预期再反转。适合避坑、科普。
- **递进反转（剧情）**：铺垫 → 升级 → 意外转折 → 落点（笑点/泪点/卖点）。适合剧情、情感。

## 3. 节奏与完播率设计

- **时长**：信息密度高的干货/口播尽量短而紧凑；剧情、深度内容可更长，但每 5–10 秒（或每两三句）要有一个新信息点、转折或“留人钩子”。
- **开头不铺垫**：删掉“大家好我是谁”之类的无效开场，第一句即钩子。
- **留客手法**：预告后文（“最后一点最重要”）、分段数字进度、画面/字幕变化、每隔几句抛一个小悬念。
- **字幕与画面**：关键句上字幕、做强调；口播配合画面演示，避免长时间单一画面。
- **口语化**：短句、第二人称“你”、具体名词和数字，少用书面长句和抽象词。
- 记录每条视频的“钩子分布位置”（第几段/第几秒出现转折或悬念），用于复现节奏。

## 4. 结尾互动与转化引导

结尾必须有明确动作，且与视频目标一致：

- **评论引导**：抛选择题/开放式问题（“你中了几条？评论区告诉我”“1 和 2 你选哪个”）。
- **收藏引导**：强调内容值得存（“建议先收藏，___的时候照着做”）。
- **转发引导**：给社交货币（“转给那个总___的朋友”）。
- **关注引导**：给关注理由（“关注我，下期讲___”），最好预告下一条。
- **转化/带货**：明确产品/服务解决什么、怎么获得（点橱窗/主页/私信关键词），先给价值再提转化。
- 引导语要自然、单一焦点，一条视频不要同时塞太多动作。

## 5. 标题、封面与话题标签

### 视频标题

- 关键词前置、包含钩子；可与开头第一句呼应。常用结构：人群/场景 + 痛点或结果 + 悬念/数字。

### 标题封面设计

封面决定点击率，需同时交代“封面内容”和“封面文字”：

- **封面内容（有什么）**：
  - 一个明确主体（人物表情 / 产品 / 前后对比 / 关键动作），主体居中或占画面约 2/3，背景干净；
  - 用构图制造焦点：人物正对镜头、产品特写、左右对比、红圈或箭头指向关键点；
  - 色调鲜明、高对比，与账号风格统一；带货类可直接露出产品与核心卖点画面。
- **封面文字（写什么）**：
  - 主大字 6–12 字，只说一个核心冲突或利益点（如“别再乱买了”“3 秒学会”），字号大、加描边或底色保证看清；
  - 可加 1 行副标题或角标补充（如“2026 最新”“自费实测”）；
  - 文字与标题互补、不重复，避免遮挡主体脸部与关键画面。

### 话题标签

- `#…#` 3–8 个，组合“1 个大流量泛标签 + 2–4 个垂直领域标签 + 1–2 个人群/地域标签 + 1 个热点标签（如契合）”。
- 从样本里汇总**反复出现的高频标签**优先复用，但要与内容真实相关，不堆砌无关热词。

## 6. 逐秒分镜脚本模板

每个方案都要把视频拆成连续时间段（每 2–4 秒一段，覆盖整条），逐段填三要素，确保可直接照拍：

| 时间 | 说什么（口播/台词） | 拍什么（画面/景别/运镜） | 屏幕文字（字幕/花字） |
|------|--------------------|--------------------------|------------------------|
| 0–3s | 钩子原话 | 景别 + 主体动作 + 运镜 | 开场大字/关键词 |
| 3–6s |  |  |  |
| … |  |  |  |
| 结尾 | 互动/转化引导原话 | 收尾画面 | 引导文字 |

填写要点：

- “说什么”写可直接念的完整句子，不是大意概括；
- “拍什么”写明景别（远/全/中/近/特写）、画面内容、人物动作、运镜（固定/推/拉/摇/跟）；
- “屏幕文字”写该时段叠加的字幕、花字、贴纸、数字或强调词；没有则填“无”。

## 7. 单条视频拆解记录模板

对每条视频填一份，再做横向对比：

```text
【视频】标题 / 作者 / 时长（可知则填）/ 发布时间 / 链接
【开头钩子】主钩子类型 + 辅助钩子 + 原话：
【正文结构】套用的结构模型 + 分段大意：
【节奏】关键信息点/转折出现的位置：
【情绪共鸣点】
【画面/BGM/字幕特点】
【结尾引导】动作类型 + 原话：
【标题与标签】标题句式 / 使用的 #标签#：
【可复用点】（创作时直接借鉴的 1–3 个手法）
【不可照抄】（属于对方原创、需改写或规避的表达）
```

横向对比后，输出“共性规律清单”：多数样本共同使用的钩子、结构、节奏、标签和引导语——创作时优先采用这些被反复验证的元素。
